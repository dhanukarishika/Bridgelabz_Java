# Bridgelabz_Java

Java assignments and practice programs completed as part of the BridgeLabz Training Program. Assignments are provided through Google Classroom (GCR) and implemented using Java in IntelliJ IDEA.

## Repository Structure

- `main` – README and daily progress updates.
- `develop` – Base Java project structure.
- `feature/coreProgramming` – Core Java programming assignments.
- `feature/object-oriented-programming` – Object-Oriented Programming assignments.
